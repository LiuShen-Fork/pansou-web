# 站点定制示例

对应后台「认证与站点」（管理控制台 → 站点设置）里新增的几项能力。所有改动保存后立即生效，清空对应字段即可恢复默认。

- 主题强调色：`site.theme_color`
- ICP / 公安备案：`site.icp`、`site.police_icp`（留空则不显示）
- 全局 CSS：`site.custom_css` → 注入 `<head>` 末尾的 `<style id="pansou-custom-css">`
- 全局 JS：`site.custom_js` → 注入 `<body>` 末尾的 `<script id="pansou-custom-js">`

---

## 1. 主题强调色

填写 `#RRGGBB`，主打按钮、链接、高亮、选中态会一起换色。系统会自动派生浅色 / 深色两套，并钳制亮度（浅色主题最亮 52%、深色主题最暗 68%），保证按钮上的文字始终可读。

| 主题 | 值 | 感觉 |
| --- | --- | --- |
| 默认紫（内置） | 留空 | 现在的样子 |
| 纯白极简 | `white` | 无彩色，近黑按钮 + 灰阶，最省眼 |
| 天青 | `#0284c7` | 冷静、偏工具感 |
| 松绿 | `#059669` | 清爽，适合资源站 |
| 石墨 | `#334155` | 几乎无彩，比纯白多一层质感 |
| 朱砂 | `#dc2626` | 强提示，慎用于大面积 |
| 玫红 | `#db2777` | 活泼，适合社区向 |

「纯白」不是简单把紫色换成灰色，而是一整套独立皮肤：背景纯白、卡片去阴影、按钮近黑、页脚与装饰诗句全部中性化，深色模式下是深灰而不是蓝黑。见 `frontend/src/assets/styles/theme.css` 的 `html[data-brand="white"]` 段。

## 2. 全局 CSS 示例

以下每段都可以单独粘贴，也可以拼在一起。

### 2.1 更柔和的圆角 + 首页标语更醒目

```css
:root {
  --radius: 1rem;
}

/* 只影响首页标语，不动控制台 */
.site-hero-slogan {
  font-size: 1.05rem;
  letter-spacing: 0.02em;
}
```

### 2.2 搜索框聚焦更明显（低视力更友好）

```css
.search-pill-input:focus {
  box-shadow: 0 0 0 3px hsl(var(--primary) / 0.28);
  border-color: hsl(var(--primary) / 0.6);
}
```

### 2.3 想低调一点：隐藏页脚的站长链接

```css
.footer-links {
  display: none;
}
```

### 2.4 打印页面时去掉装饰

```css
@media print {
  .bg-decorative,
  .footer-shell {
    display: none;
  }
}
```

### 2.5 全局字号整体上调一档（控制台也生效）

```css
html {
  font-size: 17px; /* 默认 16px */
}
```

> 用了 `rem` 的地方会跟着放大，包括控制台字号。只想放大正文、不动布局的话优先用上面 2.1 那种定点写法。

## 3. 全局 JS 示例

### 3.1 外链自动新窗口打开（防止点走当前页）

```js
document.addEventListener('click', (event) => {
  const target = event.target;
  if (!(target instanceof Element)) return;
  const link = target.closest('a[href^="http"]');
  if (!link || link.hostname === location.hostname) return;
  link.target = '_blank';
  link.rel = 'noopener noreferrer';
}, true);
```

### 3.2 接入第三方统计（以 Umami 自建为例）

```js
(function () {
  // 换掉 src 与 data-website-id 即可
  var s = document.createElement('script');
  s.defer = true;
  s.src = 'https://umami.example.com/script.js';
  s.dataset.websiteId = 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx';
  document.head.appendChild(s);
})();
```

### 3.3 页面就绪后在控制台留个标记

```js
console.info(
  '%c清羽盘搜%c 自定义脚本已启用',
  'font-weight:600',
  'color:hsl(238 52% 48%)'
);
```

### 3.4 通知类脚本：只在内容变化时执行，但监听器要自己防重

自定义 JS 的机制是「内容不变就不重复执行」，但你**改一次内容就会重新执行一次**。凡是给 `document` / `window` 挂监听器的脚本，用这个写法避免越挂越多：

```js
if (!window.__pansouCustomBound) {
  window.__pansouCustomBound = true;

  const onResize = () => {
    /* ... */
  };
  window.addEventListener('resize', onResize);
}
```

## 4. 一套完整的「纯白 + 克制」组合

后台两处填写，其余留空：

- 主题强调色：`white`
- 全局 CSS：

```css
:root {
  --radius: 0.75rem;
}

/* 纯白皮肤下把首页标语压得更安静一点 */
.site-hero-slogan {
  font-size: 0.95rem;
  letter-spacing: 0.04em;
  color: hsl(var(--muted-foreground));
}

/* 搜索框在纯白底上给一点边界，避免糊在一起 */
.search-container {
  border: 1px solid hsl(var(--border-hover));
  border-radius: var(--radius);
  background: hsl(var(--card));
  padding: 0.5rem;
}
```

效果：无彩色界面、近黑主按钮、页脚备案号仍在，装饰诗句变成淡灰。深色模式自动切成深灰底，不会闪白。

## 5. 生效与排错

- 保存后前台立即刷新，不需要重启后端；配置存在 SQLite 的 `settings` 表，随 `auth` JSON 一起落盘。
- 备案号留空即隐藏对应链接；公安备案的查询地址由号码中的数字自动拼出。
- 全局 CSS / JS 各限 256KB，超限时保存会返回 `BAD_CUSTOM_CSS` / `BAD_CUSTOM_JS`。
- JS 写错了不会白屏，但会中断该脚本后续逻辑——可在浏览器控制台看报错，修好保存即可重跑。
- 想彻底回退：清空两个文本域 + 主题强调色留空，保存。
